This release puts every pop-up menu, card and dialog under one set of rules, wakes scheduled tasks on time with a system alarm, and fixes a few spots that were hard to read or jumped around.

## One set of rules for pop-ups

- Menus, dropdowns, the quota card, the permission menu, the model panel and the project and scheduled-task dialogs now all behave the same way: only one is open at a time, tapping outside closes it, Back and Esc close the topmost one, and opening Settings, the sidebar or a full page closes them all.
- The rewind confirmation, notices and the What's New card can now be closed with Back. Before, Back closed whatever was underneath them instead.
- On wide screens with the browser pane open, project dialogs are no longer half hidden behind it: the browser steps aside while a dialog is open and comes back when it closes.
- Menus close when you rotate the screen or the window width changes; a half-filled dialog stays.

## Scheduled tasks run on time

Scheduled tasks used to need the app awake in the background, so they were missed if the system cleared the app or the device went into deep sleep. Now, whenever the next run time is set, a system alarm is set with it. When it goes off, it wakes the app, starts the background service if needed, and checks right away for tasks that are due. If you Force stop the app in system settings, Android clears the alarm too; it comes back the next time you open the app.

## Fixes

- **In portrait, the sidebar slid in again after you dragged it to a new width**: it now stays put when you let go.
- **The text on the context bar was hard to read when the context was nearly full or full**: over the warm and red fill it now uses the normal text color with an outline in the background color.
- **In Zhuyue dark you couldn't tell whether a switch was on**: the knob was white on a white track; it turns black when on.
- **Hint text in Zhuyue light was too faint**: one step darker.

## For contributors

- The front end's `app.js` is now split into 19 files under `gateway/web/app/`. The gateway joins them back in order when serving, so the UI behaves exactly as before. `node scripts/appjs.mjs` checks the syntax and maps line numbers from error reports back to the right file.
- New `scripts/contrast.mjs` computes contrast for the light and dark variants of all three looks. Run it after changing colors.
- New `scripts/ship.mjs` runs a release in one command, from bumping the version to checking the download hash.
