这一版专门修安全问题：会动到手机的操作，现在都要你在 cccodroid 里点一下才放行。

## 需要你确认的操作

- **特权命令**：AI 经 Shizuku 跑的命令，除了查看类（看系统信息、列应用、读日志之类）以外，都会先弹框问你。框里写着完整命令和是谁发起的，按钮停一秒才能点，防误触。简单的命令可以选「不再问」，带路径或环境变量的只能逐次允许。
- **设备工具**：打开设备工具总开关、把读屏切到自动或常开，都要确认一次。
- **剪贴板**：AI 每次读剪贴板都要你同意。
- **Claude Code 降级**：换渠道或固定版本时，如果会装上比现在旧的版本，先问你；不同意就保持原样，后台自动更新也不会偷偷装上。
- **预览网页**：离线预览的网页默认不能联网，页面想连外部时会提示，点「联网」才放行；点「在浏览器打开」前也会提醒你，浏览器里没有这层保护。

## 其他

- 离线安装工具包改为首次启动时「选择本地文件」，装之前会和已发布的版本核对。
- 解压时遇到会写到目标目录以外的条目，整个压缩包不展开。
- 消息超过 200 万字会提示改用文件发送。
- 扩展页组件卡片的按钮不再溢出。
- 本机 http 地址的接口也能拉取型号列表了。
