This release does three things: file paths Claude mentions can be tapped, attached images work with more third-party API setups, and prompts and conversation history get a few new safeguards.

## Tappable file paths

- Claude often wrote just "index.html" or "game/main.js", which you couldn't open or preview. It's now asked to write full paths, and if a reply slips back to bare names, it's reminded on the next turn.
- Even when it does write only a name, files it created or changed in this conversation can still be opened from its reply.

## Attached images with third-party API setups

- Some third-party API setups miss images that Claude Code reads back with the Read tool, so the model says it got no image or describes something made up. The custom provider card has a new option, "Send images inside the message (compatibility)". Turn it on if you see this; the usual route keeps working alongside it. See section 7 of the known issues.

## Prompts and conversation history

- The app no longer has any setting that appends text to the system prompt. Everything it adds is in the open source code.
- Tags that pose as system messages (such as `<system-reminder>`) in your messages, files or web pages are defused, so Claude doesn't take them as coming from the system.
- Conversation history is now sealed. If a conversation was changed outside the app or imported from a file, Claude is told when you continue it that the earlier messages may not be genuine.
- Claude asks you first before changing its own settings and hooks, output styles or conversation records, even when everything is allowed.
- Normal personalization, like editing CLAUDE.md or changing settings, isn't affected. What this does and doesn't cover is in the new "Instructions and conversation history" section of SECURITY.md.

## Other

- Fixed several security issues.
- The key card now suggests setting a daily spending limit and a balance alert in your provider's console, and revoking the key there if you think it leaked.
- SECURITY.md now explains which protections still hold depending on the state of your phone.
