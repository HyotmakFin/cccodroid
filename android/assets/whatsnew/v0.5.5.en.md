Several security fixes plus a few interface fixes. Please update.

## Important

- **Several security fixes.**
- **Shizuku pairing now needs the code and the port together**: the port is the number after the colon under "IP address & port" in the pairing dialog, so enter something like `123456 37285`.

## Fixes

- **No false "interrupted" notice**: after several sub-agents finish, reopening the app no longer says the last turn was interrupted.
- **Large spreadsheets don't freeze**: sheets with a huge number of merged cells no longer lock up the interface.
- **Extensions page**: the section buttons at the top follow along as you scroll, like the changelog, and a long path can no longer stretch the page so it slides sideways.
- **Split screen keeps your place**: resizing the split or rotating keeps a full page where you were reading.
