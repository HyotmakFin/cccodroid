## What's new

The bigger items left over from last release's changelog review are all here.

**Rewind to here**
- Every message you sent now has a rewind button. It first works out which files Claude changed after that point and how many lines, then lets you choose:
  - **Revert code only**: files go back to how they were before that message; the conversation stays as it is.
  - **Revert code and ask again from here**: opens a new conversation cut off before that message, with your message back in the input box. The original conversation is kept.
- Like `/rewind` on the desktop, only changes made with the editing tools (Edit / Write) are reverted; files changed by commands and installed packages are not restored.
- Messages from before this release have no snapshots, so only the conversation can be rewound.

**Task list**
- When Claude keeps a task list on a longer job, it shows above the input: how many items are done and which one is in progress. Tap to expand the whole list, and dismiss it once everything is done.
- The list belongs to the conversation and is still there next time you open it.
- Third-party models such as DeepSeek and GLM never got the task tools before (Claude Code only offers them to Claude models); now they do.

**Subagent steps**
- Every step a subagent takes is tucked under its Agent card. Expand it to see which commands it ran, which files it read and what it reported. Before, those steps were mixed into the main flow as if Claude had done them itself, and they didn't show up in history at all.
- While a subagent runs, its card shows what it is doing.
