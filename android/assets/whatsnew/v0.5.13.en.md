This release finishes the rest of Lineage: merge several sessions into one, pull a chapter's summary into a new conversation, see how each turn actually ran, and export the whole map.

## Lineage

- **Merge**: when a few sessions each got part of the way, tick them on the map and tap "Next". A three-step wizard asks whether each source should bring its compact summary or a few quoted turns, what you want to do next, and shows the first message so you can edit it. Sending it starts a new session, and the map draws a line into it from each source.
- **Add sources, fork from here**: under "More…" on a card you can record which sessions an existing one took over from (and undo a wrong one), or fork a new conversation straight from any session.
- **Chapter references**: write a reference like "0ab2·61" (first four characters of the session ID · chapter number) in a message and the AI receives that chapter's compact summary, so you don't have to retell it. This also works in messages you send while a reply is running. References in your own messages are tappable and jump to the start of that chapter.
- **Drill down**: tap "Drill down" on a card to lay out every turn of a chapter on a timeline: start and end, how many tool calls, how many subagents, how many errors. Sessions forked from a turn hang under that turn. Tap a turn to see how long the model thought before each tool call and how long the tool ran, plus how long each subagent took, with nested subagents indented below.
- **Export**: "Export" in the toolbar saves the current map as an image (PNG), a vector file (SVG), or a single web page (HTML) you can pan and click. Afterwards you can preview it, save it elsewhere, or share it.
- The tour has two new steps, "Merge two sessions yourself" and "Drill down", and the help page has a new Lineage section.

## Other

- Attachments over 20 MB are no longer read into the conversation in full. The AI gets the path and reads the file itself when it needs to. Files of several hundred MB now upload fine.

## Security

- Fixed several security issues.
- When testing a connection or fetching the model list, your API key is only sent to https addresses on the same host as the endpoint.
