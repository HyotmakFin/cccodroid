## Three improvements

- **You can attach several files at once.** The system file picker used to allow only one, and in some file managers picking several attached nothing at all.
- **Attachments no longer show up twice.** They used to appear in the strip above the input and again as full paths inside the input. Now they live only in the strip, where ✕ removes them; their paths are added when you send, and you can send attachments without typing anything.
- **Tap outside the slash-command list to close it.** It used to close only when you deleted the / from the input.

Thanks to the community members who reported these right away.
