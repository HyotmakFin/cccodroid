## What's new

**Custom components**
- Programs that aren't in the market can now be imported yourself: Extensions → Custom components → Import program, then pick a Linux arm64 program or its .tar.gz / .zip archive.
- The program type is detected automatically (glibc programs from Linux distros, Android native programs, static programs, scripts), and missing libraries are fetched from the Termux glibc repository.
- Once installed it's a regular command that Claude and the terminal can use, and Claude knows how it's launched. Tap "Test run" to check that it runs.
- You're responsible for where the program comes from; cccodroid doesn't review it. x86 and 32-bit programs can't run, and the import tells you so.

**What's new card**
- The first time you open the app after an update, a card in the middle of the window shows what changed. You're looking at it now.
- If you skipped a few versions, it lists the notes for up to the three newest; scroll when it's long.
- Not shown on a fresh install.

## New components in Extensions

- **Pandoc**: convert between Markdown, Word, HTML, EPUB and PDF. PDF output uses the bundled typst, so no LaTeX needed.
- **PDF toolbox**: merge, split, rotate, shrink, extract text, render pages to images.
- **Scientific Python**: numpy, scipy, matplotlib (with Chinese text in charts), Pillow, pyarrow.
- **OCR**: turn images and scanned PDFs into text in Simplified Chinese, Traditional Chinese and English, or into searchable PDFs.
- All four are verified on a real device. Once installed, Claude knows how to use them; just ask, e.g. "turn this PDF into a Word file".

## Improvements

- Uninstalling a Python-based component now also removes the cache files Python creates at run time. Before, each uninstall left a dozen MB or more behind.
