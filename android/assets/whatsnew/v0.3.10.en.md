## Choose your Claude Code version

Settings → Update now has a "Version…" button on the Claude Code row. Follow the stable or latest channel, or pin a specific release. The picker shows which version each channel currently points to, and every past release is listed and searchable. Once pinned, auto-update leaves it alone and only tells you when something newer is out.

**Toolchain devkit-2026.10.22.3**
- Adds basic commands that were missing: which, patch, ed, nano, lsof, tree and others. Some scripts failed outright without them.
- Environments created with `python -m venv` now come with pip.
- Updating the toolchain no longer carries over programs from the old version as if you had installed them yourself. The old programs that the 0.3.9 update carried over are moved aside; Settings shows how much space they take, and you can delete them right away.
- Fixed pdf-tools and ocr picking up stale old programs and failing after install.
- Uninstalling a component after a toolchain update now removes all of its files.
- All 28 community components and the browser were re-verified on a real device against this toolchain.

**Other fixes**
- Swiping back occasionally showed a "page not found" screen until you swiped again. Fixed.
- On phones in portrait, the "Start install" button on the first-run module picker could be pushed off screen. The page now scrolls.
- The extra-keys row in the terminal scrolls sideways again, so PgDn, Paste and the font-size keys are reachable.
- You can uninstall the toolchain or Claude Code on their own from Settings. Claude Code is not reinstalled automatically afterwards; you pick a version when you install it again.
- The queue notice no longer claims "session limit reached" when you only have one session; it says the previous turn is still finishing.
- The monthly usage report follows the current theme instead of always being dark.

**Upgrading from 0.3.9**: after installing, go to Settings → Update and update the toolchain to devkit-2026.10.22.3. If anything goes wrong, tap "Report on GitHub" in Settings or post in the QQ group 1062538743.
