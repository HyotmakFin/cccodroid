This version adds "Confirm sensitive actions", a safety net that also works under Allow everything, and trims the Constructivist welcome screen.

## New

- **Confirm sensitive actions** (Settings → Claude behaviour, on by default): when Claude is about to read keys or sign-in credentials (.env, SSH keys, API keys, the gateway token and so on), read the screen or tap in other apps, read the clipboard, or share a file out, a red-bordered card asks you separately, even under Allow everything. Once you allow a kind of action, it is not asked again in the same turn. It guards against instructions hidden in web pages or files that lead Claude astray. It only recognises the obvious forms, so it is not insurance for Allow everything.
- **The help page now explains what Allow everything really means**: where the risk is and when to leave it off.

## Changes

- **The Constructivist welcome screen drops the diagonal hatching and pink wedge**: they stopped at the input box and looked like half a sticker. Only the red bar under the greeting remains.

## Fixes

- Fixed several security issues, thanks to another round of outside review.
- When a project lives on shared storage (/sdcard), sub-agent briefs and reports are now kept in the app's private directory, out of other apps' reach.
- In the built-in browser, a page's intent: links now only open the address; they can no longer carry extra data into other apps.
- Notifications sent by Claude show only "Claude" on the lock screen; the text appears after unlocking.
