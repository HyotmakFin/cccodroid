## 新功能

上一版对表时剩下的几样大件，这一版都补上了。

**回退到这里**
- 你发的每条消息下面多了一个回退按钮。点了先算出这之后 Claude 改过哪些文件、增删多少行，再让你选：
  - **只撤销代码**：文件退回发这条消息之前的样子，对话不动；
  - **撤销代码，并回到这里重新提问**：另开一个会话，对话截到这条之前，原话放回输入框，原会话保留。
- 和电脑上的 `/rewind` 一样，只撤销编辑工具（Edit / Write）做的修改，用命令改的文件、装的包不会还原。
- 这一版之前的消息没有留底，只能回退对话。

**任务清单**
- Claude 干长活时列的清单，显示在输入框上方：完成了几项、正在做哪一项，点一下展开整张。全部做完可以收起。
- 清单跟着会话走，下次打开还在。
- DeepSeek、GLM 这类第三方模型以前根本拿不到清单工具（Claude Code 只给自家型号），现在也能用。

**子代理过程**
- Claude 派出去的子代理做的每一步，收在那张 Agent 卡片下面，点开能看到它跑了什么命令、读了哪些文件、最后汇报了什么。以前这些步骤混在主流程里，看着像 Claude 自己做的；历史记录里则完全看不到。
- 子代理跑着的时候，卡片上显示它正在做什么。
