## An update page fix

- **The toolkit kept showing "Error", and "Retry" said there was no update available.** If the last update check or download failed, the toolkit stayed in the error state even after a verification found every file intact, and "Retry" did nothing useful. A passing verification now returns it to "Up to date", and "Retry" checks for updates again when there is nothing to download.

## Ready for Mali GPU components

Components can now declare that they only work with ARM Mali GPUs (Dimensity, Exynos and others). On other phones they're shown as unavailable and can't be installed. The first one to use this is a community-contributed Dimensity GPU driver component.
