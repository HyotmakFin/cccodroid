## The toolchain now installs by module

The toolchain used to be a single package: about 650 MB to download and 1.8 GB unpacked, with clang, Java and ffmpeg included whether you needed them or not. From this release it is split into blocks:

- **Base** (required): Python, Node, git, ssh, curl, adb and so on
- **Command-line tools**: rg, fd, bat, jq, sqlite3…
- **C/C++ compilers**: clang, make, cmake, gdb…
- **Java and Android packaging**: javac, keytool, aapt2, apksigner…
- **Graphics libraries**, **audio/video** (ffmpeg), **other tools** (Typst, DuckDB, ImageMagick)

On a fresh install you choose which ones you want. Base, command-line tools and C/C++ compilers are ticked by default, about 330 MB to download; everything is about 700 MB. Afterwards you can add or remove modules at any time under Extensions → Toolkit modules. Each one lists its purpose, main commands, size and dependencies, and which components use it. Typing a command from a module you have not installed tells you which module has it and how big it is.

**If you are upgrading**: the toolchain update installs every module, so everything that worked before still works. Remove the ones you do not need on the Extensions page to free up space.

There are now 29 components (the browser plus 28 community ones). If a component needs a module you have not installed, you are asked to install it first.

This change touches installing, updating and repairing. We walked through each of them on a real device before release. If something will not install, an update gets stuck or a command has gone missing, tap "Report on GitHub" in Settings, or post in the QQ group 1062538743.
