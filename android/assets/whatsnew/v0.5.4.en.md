A large batch of fixes from several community reviews and issues #45 and #47–#51. Please update.

## Important

- **Permission cards show what Edit will write**: Edit / MultiEdit cards used to show only the text being removed, with the new text always empty, so you were asked to approve a change you couldn't see. A function was being silently overridden by another with the same name. Fixed, and the build check now rejects duplicate names.
- **Static text is translated again**: since the stricter security policy in 0.5.1, some fixed text in English and other non-Chinese interfaces stayed untranslated. Fixed.
- **Several data integrity fixes.**
- **Shizuku pairing**: pairing only counts as done after confirming the device actually trusts the app.

## Fixes

- **Load errors are shown**: Projects, Scheduled tasks, Capabilities, Usage, Extensions and Skills now show the error and a Retry button instead of looking empty.
- **Settings**: switches and pickers revert when saving fails; a failed key removal is reported; empty keys can't be saved. Back and Esc close Settings first, and keyboard focus stays inside the panel.
- **Scheduled tasks**: tapping "Run now" twice no longer runs the task twice; unsaved edits survive a refresh.
- **Terminal**: double-tapping the entry opens one terminal, not two; a terminal covered by another pane no longer grabs the keyboard; a failed close keeps the tab and says so; opening many terminals no longer stalls other requests.
- **Chat**: sub-agents and background tasks show "Interrupted" after you stop, instead of spinning forever; horizontal scroll in tables and code blocks is kept across updates; the view scrolls to the bottom once images load.
- **Panes and motion**: tapping the entry of an already-open pane brings it to the front; going back before a page or the sidebar has fully opened no longer jumps to fully open first; text from the old and new screens no longer overlaps when moving in and out of Settings sections, switching between pages, or opening and closing project and task details (all four themes).
- **Lower memory in long chats**: history pages trimmed while scrolling and closed long Markdown previews are released.
- **Reloads** (switching language, changing the run mode, etc.) keep the unsent draft in the input box.
- **Notifications**: tapping a "Done" notification while the app isn't running opens the right session.
- **Diagnostics**: tokens and authorization codes in URLs are redacted.

## Accessibility

- New "Extra large" text size.
- The default theme's primary buttons are a little darker so white text reads more easily.
- With motion off, the few remaining fade-ins are off too.
- Toasts are announced by screen readers; the goal timer no longer makes them read out every second.
- Longer Russian, French and other translations no longer get cut off on narrow screens.
