This is the last release of 0.4.x, and it's about making the app yours: a new appearance, your own accent color and fonts, saved prompts, and your choice of buttons on the top bar and under messages.

## New appearance: Construct

- Settings → General → Appearance now has Construct: kraft paper, ink black and poster red, with square corners, heavy lines and solid offset shadows. Buttons drop into their shadow when pressed. Light and dark are both included.
- Avatars, the input box, menus and settings panels all go square too; the start screen gets fine diagonal lines and a red bar under the greeting.

## Accent color

- Settings → General → Accent color: eight presets, or tap the rainbow circle at the end to pick your own. Buttons, links and selected items all take that color.
- The color is lightened or darkened for the current appearance so text stays readable in light and dark, and text on buttons switches between black and white automatically.

## Import fonts

- Settings → General → Imported fonts: import a ttf, otf, woff or woff2 file (up to 40 MB each, 10 at most).
- The interface font and the reply font each have Custom…, where you pick from the imported fonts. Characters a font lacks still come from the built-in fonts, so a Latin font won't leave Chinese text blank. Code and the terminal keep the built-in monospace font so columns stay aligned.

## Saved prompts

- The Extensions page has a new Saved prompts section: save a long prompt you send often under a name, then pick it by typing / in the input box. Whatever follows `/name` fills `$ARGUMENTS` in the text.
- A prompt can be for all projects or just the current one. They're stored as standard Claude Code command files, so claude in the terminal can use them too.
- Saved prompts come first in the slash list, with their description and argument hint, and the list starts with Manage saved prompts….

## Buttons on the top bar and under messages

- Settings → General → Top bar buttons: Files, Terminal, Browser, Command palette and New session can each be Pinned (always visible, no need to tap ⋯ first), In ⋯, or Hidden. Hold the handle and drag to reorder.
- The row of buttons under each message (copy, resend, rewind, bookmark, delete / copy, share, fork, bookmark, delete) can hide the ones you don't use, set separately for your messages and Claude's replies.
- These choices, along with pinned sidebar items, are stored in the app's own data, so clearing the WebView cache won't lose them.

## Fixes

- **A sliver of the usage line showed above full pages**: at display scales like 0.87, the top of a full page sat less than a pixel below the top bar. It now lines up with the actual height, and the usage line isn't drawn while a full page is open. (#39)
- **The top bar status flickered when tapping New chat repeatedly on an empty new chat**: if you're already on a new chat with nothing sent, tapping New chat in the sidebar or ＋ in the top bar now just closes any full page and puts the cursor back in the input box, instead of reconnecting on every tap. Thanks to chenshi723 for the detailed analysis. (#40)
