## Fix: pinyin wouldn't type into the message box right after opening the app

This one followed us for several releases: open the app, tap the message box, the keyboard comes up and shows suggestions, but picking one puts nothing in the box. English worked, and going to split screen or switching apps made it go away.

This time we recorded everything passing between the keyboard and the page, and found the cause. The app puts the cursor in the message box as soon as it opens. The keyboard isn't up at that moment, so the system never connects the keyboard to the box, and the keyboard is left holding an empty connection. When you then tap the box, the cursor is already there, so nothing replaces that connection, and every character you pick goes into it.

Now, when you tap the message box, the app checks that the keyboard is really connected to it and, if not, has it reconnect. That's what the system does when you go to split screen or switch apps; now it happens without you.

Thanks to the group members and the test tablet for reproducing it again and again.
