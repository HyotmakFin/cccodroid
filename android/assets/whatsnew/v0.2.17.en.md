## Fallback sources for downloading Claude Code

On some networks the official Claude Code download can't be reached, or drops halfway. First install and in-app updates now switch sources automatically:

- The official server is tried first. If it can't be reached or drops twice in a row, the app moves on to npmmirror, Tencent Cloud and the official npm registry in turn, resuming what was already downloaded. Whichever source worked last time is tried first next time.
- It's the same program either way: Anthropic also publishes Claude Code on npm, and these mirrors simply sync it.
- Wherever it comes from, the file has to match the **SHA-256 in Anthropic's official manifest** before it's installed. If the official manifest can't be reached either, the app uses the copy on cccodroid.net, which carries Anthropic's signature and is only used once that signature checks out.
- If even that copy can't be reached, the app checks npm's own registry signature, installs, and re-checks against the official manifest automatically once it's reachable again.
- The npm package is compressed, under half the size of the official direct download, so it's often faster too.
