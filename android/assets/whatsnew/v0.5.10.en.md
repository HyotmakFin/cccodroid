This release is mostly security hardening, plus two small interface fixes.

## Security

- Fixed several security issues.
- The first time you turn on screen reading and tapping, a native dialog now asks you first. cccodroid used to switch the accessibility service on directly, skipping the system's warning.
- All-files access is now something you turn on yourself in system settings. With Shizuku granted, cccodroid used to turn it on for you.
- Turning wireless debugging back on and re-activating Shizuku after a reboot is now off by default. If you want it, turn on "Reactivate automatically after a reboot" under Settings → Device & permissions.

## Interface

- The "running" badge next to Chats in the sidebar no longer has a background, so it sits better on the selected row.
- The QQ group number in the release notes and the close button in the model picker no longer show a focus ring when they open.
