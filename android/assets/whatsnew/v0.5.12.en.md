This release adds tap-to-load for external images and continues the security hardening.

## New

- When you preview or edit a Markdown file, images it pulls from the web now show as a button naming the site they come from, and only load when you tap it. That way the image's server can't see your IP address and when you're reading the moment you open the file. If you don't want this, turn off "Load external images on tap" in Settings and images show directly as before.

## Security

- Fixed several security issues.
- When testing a connection or fetching the model list, your API key is only sent to https addresses on the same site as the endpoint.
- Downloading an on-device model now stops automatically when less than 1 GB of storage is left, instead of filling up the phone.
