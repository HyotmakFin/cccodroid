## Claude Code 下载多了后备来源

有的网络连不上 Claude Code 的官方下载地址，或者下到一半就断。现在首次安装和应用内更新都会自动换来源：

- 先连官方；连不上、或者连着断两次，就依次换阿里（npmmirror）、腾讯云、npm 官方源，接着已下的部分续传。下一次优先用上次成功的那个。
- 换来的是同一份程序：Anthropic 自己也把 Claude Code 发在 npm 上，这几个镜像只是同步了它。
- 不管从哪下，装之前都要和**官方清单的 sha256** 一致。官方清单本身也拿不到时，用 cccodroid.net 上的清单镜像，那份带着 Anthropic 的签名，验过才用。
- 连清单镜像都拿不到时，改验 npm 官方的签名先装上，之后连得上官方时自动补核一次。
- npm 上的包是压缩过的，体积不到官方直链的一半，下载反而更快。
