## What's new

**HTML preview**
- Opening an `.html` file in the file viewer now shows it as a web page. CSS, JS and images in the same folder or subfolders load too, so you can play the browser games Claude writes right there.
- The preview reloads whenever the file changes, so you can watch while Claude works on it.
- Switch to the source to edit it, or open it in the browser, from the top bar.
- The page runs in its own sandbox: its scripts can't reach the app, your sessions or your keys, and it can only read files in its own folder.
- Claude knows about this too: for a static page it now writes the file and gives you the path, instead of starting a local server.
