又来一份安全审核，能修的都修了，建议更新。

## 安全

- **Shizuku 配对**：配对时如果同时冒出好几个配对服务，不再自动挑一个发码，会请你把配对框里的端口和配对码一起填上。这样可以防同机别的应用冒充配对服务。
- **Claude Code 不再被自动换成旧版本**：自动更新只往新版本升。要换到更旧的版本（比如从 latest 切回 stable），得你自己点更新。
- **特权命令通道**：关掉了旧的全机共享通道。现在只走 App 私有目录里的那条，别的应用抢不走，也冒充不了。
- **工具包**：构建时会核对 Termux 官方的仓库签名。从下一版工具包起，清单缺签名就不发布。
- **下载**：加密的下载地址如果被重定向到不加密的 http，就不下载。
- **通知和诊断包**：要你确认的通知，锁屏上只显示标题，不露出命令内容。诊断包里 JSON 格式的密钥也会抹掉。

## 修复

- **定时任务**：cron 写了特别大的范围（比如 `1-99999999999`）时，网关会卡死，重启后还会再卡。现在不会了。
- **长时间运行**：网关里缓存的事件设了总量上限，大文件写多了不会越占越多内存。
- **导出会话**：一次导出加起来超过 768 MB 时，会提示你分几次导出，不会把网关撑崩。
- **终端**：和网关断开时立刻提示正在重连，不再一直没有反应。
