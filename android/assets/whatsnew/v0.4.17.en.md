This release is about reading long chats: scrolling up while Claude is still answering no longer yanks you back down, switching chats no longer replays them, and there are now bookmarks. The toolkit is updated too.

## Bookmarks

- **Tap the bookmark button under a prompt or reply** to leave a marker right there. Both rows now have five buttons. On a long reply, the bookmark points to the paragraph you're reading, not just the start.
- **A new Bookmarks page in the sidebar** groups them by chat. Tap one to jump straight to it; the paragraph briefly highlights. Tap ✕ to remove one.
- **Chats reopen where you left off**, with nothing to tap. If you switched away before reaching the bottom, you come back to the same spot; if you'd read to the end, the chat opens at the latest message as usual.

## Reading long chats

- **Scrolling up during a reply no longer jumps or snaps back to the bottom** (#34). Scroll back down to resume following.
- **Switching back to a chat you already opened no longer replays the old content** (#36). A reply in progress shows up as far as it has got.
- **Tapping the page or chat you're already on no longer makes the page jump** (#37). It just closes the sidebar.
- **Chat sizes in the list can be tapped for an explanation** (#35): it's the size of the local transcript file, not how much context is used.

## Other improvements

- **The terminal scrollbar on the right is easy to drag**: the thumb now follows your finger, and tapping the track jumps there.
- **The context bar no longer outlines its text when nearly full**: the text is split into two colors at the progress edge, readable on both sides.
- **The account menu no longer offers "Sign out" when you aren't signed in** to an official account. It shows "Sign in" instead.
- **The docked sidebar's collapse button lines up with the top bar's menu button** (#31).
- **Faster component verification**: components with many small files, such as GPU drivers, used to sit on "Verifying" for a long time.
- **The model list opens without waiting for models.dev**, which is now fetched in the background.
- **Toolkit updated to devkit-2026.10.28**, with two new optional modules, Go and Node.js. Install them from Settings → Updates when you need them.

## Community contributions

- **Workspace access through the system file picker** (#30): open and save cccodroid's files from your file manager.
- **Context window filled in from models.dev** when a compatible endpoint doesn't report one (#32), so context usage can be shown.
- **Permission mode in Settings is a native dropdown again** (#33), instead of a row of cramped abbreviations on phones.
