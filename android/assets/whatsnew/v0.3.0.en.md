## The first stable release

From now on, 0.3.x updates only fix problems and add no new features, so this is a version you can settle on.

**A place to talk**
- GitHub Discussions is open for ideas and questions, in English or Chinese. There is also a Chinese-speaking QQ group, 1062538743 (see below, or the last section of Help).
- For bugs, Settings → Report on GitHub is still the best route: your device and self-test results are filled in for you.

**We'd love your help**
cccodroid has been built by one person so far, and there are far too many Android devices for one person to test:
- tell us how it runs on your device, even if everything works (the "Device report" issue template);
- fix a translation that reads awkwardly;
- if you write code, every pull request now gets an installable build automatically, with no setup on your side.

The contributing guide in the repository explains how.
