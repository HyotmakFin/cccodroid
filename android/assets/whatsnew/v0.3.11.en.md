## Fix: "Start install" missing on phones during first-time setup

In 0.3.10, on phones in portrait, the "Start install" button on the toolchain module page could end up below the screen with no way to scroll to it, so setup could not continue. The button and the download total now stay pinned at the bottom of the page, and the module list scrolls on its own above them.

Thanks to Goa in the QQ group for reporting it right away and testing the fix.

If you have already finished setup, this did not affect you; nothing else changed in this release. See the 0.3.10 notes for what that release added (Claude Code version picker, toolchain devkit-2026.10.22.3 and more).
