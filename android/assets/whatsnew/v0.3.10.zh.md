## Claude Code 想用哪一版，自己定

设置 → 更新里，Claude Code 一行多了「版本…」：可以跟随 stable 或 latest，也可以固定在某一版。选单里标着 stable、latest 眼下各是哪一版，全部历史版本都能搜。固定以后自动更新不会再动它，有新版只提醒一句。

**开发工具包 devkit-2026.10.22.3**
- 补上了 which、patch、ed、nano、lsof、tree 等基础命令，原来缺了它们，有些脚本会直接跑不起来。
- `python -m venv` 建出来的环境终于带 pip 了。
- 升级工具包时不再把旧版本的程序当成你自己装的搬过来；0.3.9 升级时搬过来的那批旧程序，会挪到一边隔离，设置里能看到占了多少，可以立即删掉。
- 修了装 pdf-tools、ocr 后，用到的仍是旧版程序、一跑就报错的问题。
- 换过工具包以后再卸组件，能删干净了。
- 全部 28 个社区组件和浏览器，都在这版工具包上重新真机验证过。

**其他修复**
- 侧滑返回偶尔出现「找不到网页」，要再返回一次才恢复：修好了。
- 手机竖屏首次安装时，模块勾选页的「开始安装」被挤出屏幕、划不到：现在能滚动了。
- 终端底部的补键行能左右划了，后半截的 PgDn、粘贴、字号这些键够得着了。
- 设置里可以单独卸载开发工具包或 Claude Code。卸了 Claude Code 不会再自动装回，想装时再选版本。
- 排队提示不再动不动就说「会话已到上限」，只开一个会话时会如实说明是上一轮还没收尾。
- 使用月报跟着当前外观配色走，浅色主题下不再是一块深色。

**从 0.3.9 升级**：装好新版后，到 设置 → 更新 把工具包升到 devkit-2026.10.22.3。碰到问题请在设置页点「到 GitHub 反馈」，或在 QQ 群 1062538743 里说一声。
