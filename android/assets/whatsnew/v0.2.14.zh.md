## 新功能

**到 GitHub 反馈**
- 设置 → 排障 多了一个「到 GitHub 反馈」。点了会打开 GitHub 的新建 Issue 页面，机型、系统版本、各家 ROM 版本、芯片、自检结果、装了哪些组件都已经填好，你只要写遇到了什么。
- 不放日志、密钥、账号和对话。打开前会先给你看要填进去的内容。需要 GitHub 账号；没有的话照旧用「打包诊断」。

**已知问题按厂商分节**
- 网站的「已知问题」加了一节，按品牌写：小米、OPPO / 一加 / 真我、vivo、华为 / 荣耀、三星、Pixel、红魔 / 中兴、联想，各自的后台设置怎么开，哪些芯片用不了 GPU 组件。
- 哪些是实测、哪些只是常见路径，都标清楚了。目前实测只有两台，你的机型有问题请务必反馈。

## 改进

- 界面不是中文时，组件自带技能的说明也显示英文。
- 端侧模型的下载目录改由组件签名索引提供，以后增删模型不用等发版。
- 滚动冻结的自动脱困：内容只比屏幕长一点点时不再误判；每次脱困都会记进网关日志，方便以后查根因。
- 扩展页的组件都打了适配当前工具包（devkit-2026.10.18）的版本，17 个全部真机验证过。之前显示「还没有适配当前工具包的构建」的问题已经解决；装过 GPU 驱动的，卡片提示重装时点一下即可。
