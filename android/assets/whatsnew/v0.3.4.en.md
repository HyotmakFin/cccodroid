## New: device tools (off by default)

Turn them on in Settings → Device tools and Claude can use a few phone features directly: post notifications, read and write the clipboard, share a file to another app, open a link or an app, check battery and network. Handy for having Claude test an app you're building, or send a PDF, image or APK it made to a chat app.

- Every tool can be switched off on its own. Calendar, alarm, email and the like are only pre-filled; you tap save or send yourself.
- **Screen reading and tapping** use the accessibility service, a separate setting that's off by default. In "on when needed" mode the service stays off until Claude needs it and switches itself off after a few idle minutes, so it doesn't run all the time or drain the battery (needs Shizuku activated).
- While on, every turn carries one or two thousand extra tokens of tool descriptions, so leave it off when you don't need it.

## A display fix

- **Ordinary commands showed an empty "Subagent steps" section.** Newer Claude Code versions count longer-running commands as "tasks", and we mistook them for subagents. Only subagents get that section now.
