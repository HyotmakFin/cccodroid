This release ships two install packages: the regular build (targetSdk 28) and a 36 build for newer systems. You can also update straight from the account menu, collapse the sidebar's conversation groups, and drag to set the compaction point on the Providers & Models page.

## Two install packages

- Releases and the download page now include `cccodroid-36.apk`. Both builds have the same features, version and signature, so either one installs over the other without losing data.
- The regular build is the one to pick. If your phone refuses it (saying the target version is too old), install the 36 build instead.
- Settings → Update has a new "Install package" row. Set to "Auto" it follows whichever build is installed; you can pick 28 or 36 and the next update switches over.
- On phones that only accept the 36 build, switching back to 28 shows a warning and is refused, so updates keep installing.
- Tools and components work on both builds; every component has been run on a real device with the 36 build.

## Other improvements

- The account menu has an "Update" item that shows how many updates are waiting, so you no longer dig through Settings.
- Tap "Today", "Yesterday" or "Earlier" in the sidebar to collapse or expand that group; it stays that way next time.
- The Providers & Models page has a "Compaction line" slider: drag it to where the context should start being compacted, or tap "Let claude decide" for the default.
- The "connect a model" card on the home screen no longer shows up when any provider has a key.
- After an in-app update installs, the app opens itself again.
