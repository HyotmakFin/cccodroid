## Security and stability fixes

A community member did a careful code review and reported ten problems. All of them are fixed in this release:

- **The trash cleanup API could delete all app data.** A program holding the gateway token could wipe the app's home folder with one crafted request. Tapping "Empty trash" never triggered it. Names that escape their folder are now rejected, and the skill-delete API got the same fix.
- **HTML previews could reach the gateway through the native bridge.** A previewed page could use the in-app browser to open files as the gateway. Files served by the gateway can no longer run scripts, and the in-app browser and pane refuse the gateway's own address.
- **HTML previews could follow symlinks out of the preview folder.** The real path is now checked.
- **A crafted token could crash the gateway.** It is now simply rejected.
- **Chinese text or emoji occasionally turned into � while streaming.** A character split across two chunks wasn't reassembled; output is now decoded as a stream.
- **Attaching two files with the same name in the same second overwrote the first.** The second one is now renamed.
- **The editor's conflict check could miss a change made while a save was being received.** It now compares after the whole body arrives.
- **An interjection could be lost if the app was force-stopped before it was delivered.** It is now saved right away and comes back to the queue on the next launch.
- **A Claude Code update that failed its test run left you without a working version.** The new version is now tested before it's switched in.
- **Importing an archive that expands to a huge size could take down the gateway.** There is now a size limit.

**Skill import** is also fixed: every skill in an archive is installed, you can pick several files at once, archives forwarded from chat apps are no longer greyed out in the file picker, and a single SKILL.md can be imported directly.

Thanks to the reviewer, and to everyone who reported the skill import problems.
