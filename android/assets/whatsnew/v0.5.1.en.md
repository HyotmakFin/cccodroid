This release fixes a batch of issues found in a code audit — security holes, ways to lose data, and occasional hangs — so please update soon. It also fixes the UI on older system WebViews.

## Security

- **Another app on the same phone could pose as the gateway**: if it grabbed the gateway's port first, the app would hand it your credentials. The app now verifies the gateway's identity first and refuses if it doesn't match, telling you the port is taken. The UI's login cookie is also regenerated on every start.
- **Other apps could connect to the privileged command channel**: priv and the device tools now use a channel inside the app's private directory.
- **Toolkit manifests installed without a signature check**: full-toolkit updates and repairs now require either the version pinned in the APK or a valid signature.
- **Anyone could use the on-device model's API**: llama-server now starts with a key. The local forwarding layer used for stream fixing also gets a random password on each start.
- **The UI now has a Content Security Policy** that blocks inline scripts, and cookie-bearing requests from other sites are rejected.
- Custom provider environment variables can no longer set things like `PATH`, `LD_*` or `NODE_*` that change how programs run.
- More hardening: path and hard-link checks when unpacking, external links limited to http(s) and mailto, size limits on downloads, shared files and custom component uploads, and USB access only trusts the system's permission.

## Fixes

- **Settings and provider config could lose your keys if the app was killed mid-write**: they are now written to a temp file and swapped in.
- **Moving a session while it was generating, or deleting its project with the folder, could lose that turn**: this is now blocked while generating.
- **Scheduled task retries still ran after the task was turned off, paused or deleted**: they are now cancelled too.
- **Archiving or filing into Misc reported success even when the write failed**: it now tells you.
- **Pasting the same model link twice while it was downloading** made two downloads write to one file: the second is now refused.
- Switching sessions while waiting for a send to be acknowledged no longer files that turn under the new session.
- Background subagents no longer flip an idle main session back to "generating"; subagent cards now tick every second.
- Search no longer keeps the whole index in memory when you have many sessions.
- If moving your own installed packages once hung at the end of a toolkit install, it is now skipped on later starts instead of hanging every time. (0.4.17, Meizu 18)

## UI

- **Custom accent colors now apply everywhere**: the loading animation, install screen, dialogs, browser toolbar, and the slanted block on the Construct home screen.
- **Older system WebViews (around Chrome 104)**: pending permissions hidden inside collapsed subagent lists, phone layouts rendered as wide-screen, and missing spinners and diff backgrounds are all fixed.
