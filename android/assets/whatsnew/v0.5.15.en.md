This release adds the Material theme and automatic session titles, and updates now try several download sources at once and use the fastest.

## New

- **Material theme**: pick "Material" under Settings → Appearance and the whole interface takes its colors from your wallpaper (Material You).
- **Automatic titles**: after the first reply in a new chat, the session gets a title on its own. Names you set yourself are never overwritten. Under Settings → Provider & model → Auto-title you can choose which model writes titles, or turn it off.
- **Cleaner model picker**: the model picker under the input bar only lists providers you can actually use. A Claude account you haven't signed in to, or an on-device model you haven't downloaded, no longer shows up. Every provider also has a "Show in the model picker" switch in Settings, so you can hide ones you don't want to see without losing their configuration.
- **OpenAI bridge**: once the component is installed, you can enter its address and key and pick a model right on its card in Extensions, no more editing config files by hand. Uninstalling cleans up its registration first. Thanks to chenshi723.

## Updates and downloads

- Update checks query GitHub and both mirrors at the same time and use whichever answers first, so they work without a proxy.
- Before downloading, each source gets a quick speed test and the fastest one is used. If a source fails or the file doesn't verify, the next one takes over automatically. The update page shows where the file came from.
- Fixed: a queued message left behind in a deleted session could make the devkit update say "a task is still running" forever, even after a restart.

## Other

- The usage readout at the bottom shows elapsed time and output tokens live while a reply is running, freezes when it's done, and is remembered per session.
- Copying a message with attachments no longer includes the attachments' full paths.
- Model lists written inline are supported and their context sizes are read correctly (#57).

## Security

- Fixed several security issues.
