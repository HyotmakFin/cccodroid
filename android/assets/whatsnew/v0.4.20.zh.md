这一版是 0.4.x 的最后一版，主题是「按自己的习惯摆」：多了一套外观，强调色和字体能换成自己的，常发的提示能存成指令，顶栏和消息下面留哪些按钮也由你定。

## 新外观「构成」

- 设置 → 通用 → 外观，多了「构成」：牛皮纸底、墨黑、宣传画红，方角、粗墨线、实心错位投影，按钮按下去会往投影那边落一下。浅色深色两套都有。
- 头像、输入框、弹出菜单、设置面板都跟着换成方的；首屏铺一层细斜线，问候下面压一道红。

## 强调色

- 设置 → 通用 → 强调色：八个预设色，或者点最后的彩色圆自己取色。按钮、链接、选中项都换成这个颜色。
- 同一个颜色会按当前外观的底色自动调深浅，浅色、深色下文字都看得清；按钮上的字自动选黑或白。

## 导入字体

- 设置 → 通用 → 导入的字体，选一个 ttf、otf、woff 或 woff2 文件导进来（单个 40 MB 以内，最多 10 个）。
- 界面字体和回复字体各有「自选…」，点了从导入的字体里挑。字体里没有的字照旧用自带字体补上，英文字体配中文也不会缺字。代码和终端仍用自带的等宽字体，免得格子对不齐。

## 常用指令

- 扩展页多了「常用指令」：常发的长提示存成一条，起个名字，之后输入框里打 / 就能选。`/名字` 后面跟的话会填进正文里的 `$ARGUMENTS`。
- 可以存给所有项目，也可以只存给当前项目。存的是 Claude Code 官方的命令文件，终端里直接敲 claude 也能用。
- 斜杠列表里常用指令排在最前，带说明和参数提示；列表顶上有「管理常用指令…」。

## 顶栏和消息下面的按钮

- 设置 → 通用 → 顶栏按钮：文件、终端、浏览器、命令面板、新会话，每个都能选「常驻」（一直露着，不用先点 ⋯）、「收进 ⋯」或「隐藏」，按住把手拖动换顺序。清单按常驻、收进 ⋯、隐藏分成三组，和顶栏上看到的顺序一致；点 ⋯ 展开时常驻的原地不动，收起的从 ⋯ 旁边滑出来。
- 消息下面那一排按钮（复制、重发、回退、书签、删除 / 复制、转发、分叉、书签、删除）用不上的可以藏起来，你的消息和 Claude 的回复分开设。
- 这些选择和侧栏常驻项一起，存在应用自己的数据里，清 WebView 缓存也不丢。

## 修复

- **打开整页时顶上漏出一丝用量条**：在 0.87 倍这类缩放下，整页上沿和顶栏之间差了不到一像素。现在按实际高度对齐，整页开着时也不再画用量条。（#39）
- **空白新对话页上反复点「新对话」，顶栏状态来回闪**：已经在一张还没发过消息的新对话上时，再点侧栏「新对话」或顶栏 ＋ 只收起整页、把光标放回输入框，不再每点一次就重连一遍。谢谢 chenshi723 的详细分析。（#40）
