## No more GitHub errors where github.com is blocked

The "Development kit" row under Settings → Update used to show an error on networks that can't reach github.com. If the toolkit you have is the one this app version ships with, it no longer goes online to check; when it does check for a newer one and GitHub is unreachable, it falls back to the cccodroid.net mirror. Thanks to Goa for reporting and testing.

## In-app notices

When something important comes up (a download source is down, a release has a known issue), we can post a short notice through the website. It only shows when you open the app or come back to it, never while you're working, and waits until the next launch if it would collide with the release notes. Tap "Got it" and that notice won't come back. Notices are signed, and the app only accepts ones with a valid signature.

## Check records

New under Settings → Troubleshooting: "Check records" compares the install records of components, toolkit modules and custom components with the files actually on the device, and tells you what doesn't match and how to fix it. It also runs once after the app starts; if it finds something, it shows up in Settings and in the repair ledger.
