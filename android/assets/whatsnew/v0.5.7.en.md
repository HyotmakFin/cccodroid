This release fixes the issues still open from chenshi723's re-test report (#52), including several that only show up at particular moments. Thanks, chenshi723.

## Fixes

- **Stop means stop**: messages you added mid-turn that Claude hadn't read yet are now held along with the queue when you stop, instead of being sent on the next turn.
- **Two messages sent while the gateway is stuck no longer split into two conversations**: if the first still hasn't arrived after 15 seconds, the second isn't sent and you're asked to try again shortly.
- **"Give up goal" works after switching conversations**: the clear goes to the conversation it belongs to, not the one you switched to.
- **Rewind, fork and delete no longer pick the wrong turn**: when the same message appears several times and it's unclear which one you mean, you're told so instead of the closest match being chosen.
- **Failed refreshes are flagged**: when usage, capabilities, projects or scheduled tasks can't load new data, they're marked "showing what was last loaded" with a retry button.
- **Monthly report buttons are greyed out until data loads**, instead of looking clickable and doing nothing.
- **New project folder preview is accurate**: if a folder with the same name already exists, the preview shows the actual -2 / -3 path.
- **Scheduled tasks**: you can't save while the model list is still loading (which could save a new provider with an old model), and run-count or end-date limits must be filled in.
- **Built-in browser**: `localhost:3000?q=…` and `localhost:3000#…` are recognised as addresses.
- **Lineage**: a scheduled-task run whose conversation is in the trash can be restored by tapping it.
- **Spreadsheets**: merged cells with hidden rows or columns display correctly, and the cell bar shows the right address.
- **Unreadable project instructions or usage ledger now show an error** instead of being treated as empty, so saving can't overwrite the original CLAUDE.md.
- **Tapping the title of the conversation you're already in leaves it as is**, even while it's loading or you're reading an earlier section. Use the button at the bottom right to jump to the latest.
- **Bookmarks**: if an identical message further down hasn't been confirmed as saved, the bookmark waits, so it doesn't land in the wrong place.
- **"Writing Bash arguments" no longer reappears while a command runs**: it sometimes came back after the tool had started and kept counting up.
- **Quick switching doesn't mix things up**: late replies no longer overwrite what's on screen when you switch conversations, models or settings.
- **Keyboard and screen readers**: focus moves into dialogs when they open, Tab stays inside them, and focus returns when they close; radio cards work with arrow keys; the model button opens with Enter.
- **Motion**: with motion off, the wide-screen + panel no longer fades in, and history messages no longer fade in when you open a conversation.
- Long translations such as Russian no longer push settings buttons off screen, and the attachment strip no longer touches the edge.
