Fixes from another security review — please update. The blinking cursor while replies stream also looks smoother now.

## Security

- **HTML previews could read secret files in the same folder**: scripts in a previewed page used to be able to read files like `.env` or private keys next to it. Dot files and folders (`.env`, `.git`, …), private keys and certificates are no longer served to previews; the page's own styles, scripts and images still load. Preview links now expire after an hour of inactivity.
- **Links disguised as the local gateway could open outside pages in the main UI**: addresses like `127.0.0.1:port@another-site` used to slip past the check; the real destination is now checked.
- **Old files posing as new ones**: an old component index dropped into shared storage by another app is no longer used, and toolkit manifest signatures are now tied to their version (from the next toolkit release).
- **Opening Word documents**: cleanup now keeps only the tags and attributes needed for layout. The UI can no longer be embedded in other pages.

## Fixes

- **Deleting a project together with its folder**: the check now happens before conversations are touched (previously they went to the trash even when the delete was refused). The app's own data folder and top-level storage folders (Download, DCIM, …) can no longer be deleted this way.
- A malformed value in settings no longer breaks every following turn.

## UI

- **Cursor while replying**: still a blink, but the switch no longer jumps in a single frame, so it no longer looks choppy.
