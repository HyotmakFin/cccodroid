Fixes from yet another security review — please update.

## Security

- **Shizuku pairing**: if several pairing services show up at once, the app no longer picks one and sends the code. It asks you to enter the port from the pairing dialog together with the code, so another app on the device can't pose as the pairing service.
- **Claude Code is never auto-downgraded**: automatic updates only move to newer versions. Going back to an older one (e.g. switching from latest to stable) now waits for you to tap Update.
- **Privileged command channel**: the old device-wide channel is closed. Only the one in the app's private folder is left, which other apps can't take over or impersonate.
- **Toolkit**: builds now verify Termux's official repository signatures, and from the next toolkit release on, a manifest without a signature won't be published.
- **Downloads**: an encrypted download that gets redirected to plain http is refused.
- **Notifications and diagnostics**: permission prompts show only the title on the lock screen, not the command. Diagnostic bundles now also scrub keys written in JSON form.

## Fixes

- **Scheduled tasks**: a cron field with a huge range (e.g. `1-99999999999`) used to freeze the gateway, and it froze again after each restart. That no longer happens.
- **Long sessions**: the gateway's event cache now has a total size cap, so writing many large files no longer keeps growing memory.
- **Exporting conversations**: exports totaling more than 768 MB now ask you to split them up instead of crashing the gateway.
- **Terminal**: losing the connection to the gateway now immediately shows that it's reconnecting instead of staying silent.
