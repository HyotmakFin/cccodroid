## Smoother downloads on restricted networks

**Optional components**
- Component packages can now also come from dl.cccodroid.net, not just GitHub. When GitHub stalls, the download switches over and resumes where it left off, and whichever source worked is tried first next time.
- The progress bar shows where the download is coming from.
- Switching sources doesn't weaken anything: both serve the same file, and it's always checked against the SHA-256 in the signed index before installing.

**Installing packages on the device (pkg install)**
- Added the Termux mirrors at Tsinghua, USTC, BFSU and Nanjing University. If the official repository can't be reached, pkg switches to them automatically.
- Repository indexes now have to pass Termux's official signature before they're used, so a mirror is as trustworthy as the official server.
- One repository being unreachable no longer blocks packages from the others.

**Claude Code**
- In the unlikely case that a build fails its later check against the official manifest, the update card now says so, and tapping Update downloads it again.
