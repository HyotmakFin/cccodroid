# cccodroid 使用帮助

cccodroid 在手机上跑**官方原版 Claude Code**，外面套一层图形界面，再配一整套开发工具（Python、Node、clang、git、ffmpeg……）。Claude 能读写文件、跑命令、开本机服务，就像在电脑终端里一样。

## 快速上手

1. **第一次打开**要装开发工具包（约 650 MB）和官方 Claude Code（约 230 MB）。工具包会先问你从哪装：**GitHub**、**cccodroid.net 镜像**，或者**本地文件**（比如用电脑下好拷进来的 `devkit-cc.codroid.tar.gz`，下载地址见 [cccodroid.net/download](https://cccodroid.net/download/#devkit)）。两个下载源互为备用，一个不顺会自动换另一个接着续传；不管从哪来，都按 APK 自带的 SHA-256 核对。下载前会先算空间，不够会直接告诉你要多少。
2. **接上模型**（设置 → 接口），两条路选一条：
   - **Claude 账户登录**：有 Pro / Max 订阅或 Console 账户，在浏览器里授权一次，自动回到应用，不用填 Key。
   - **填 API Key**：Anthropic 的 Key，或 DeepSeek、智谱 GLM、通义千问、Kimi 的官方兼容接口，也可以加任意兼容接口。
3. **发第一条消息**：新会话里有几条示例，点一下只是填进输入框，改好再发。

> Key 只存在应用私有目录，由 Claude Code 按需读取，不进环境变量；账户登录由 Claude Code 自己完成，应用不碰凭据。

## 界面一览

**顶栏**（从左到右）：

| 按钮 | 作用 |
|---|---|
| ☰ | 侧栏：会话 / 设置 / 能力 / 扩展 / 帮助 |
| 📁 | 文件浏览器 |
| >_ | 终端 |
| 🌐 | 应用内浏览器 |
| ‹› | 命令面板（斜杠命令） |
| ❄ | 冻结脱困：划不动了就点它（见「排障」） |
| ＋ | 新会话 |

顶栏下面那条细线是**上下文用量**：这个会话已经占了模型窗口的多少，越往右越满，快满时会变色。

**输入区**：

- ＋：常用操作菜单（附加文件、切换模型、思考强度、查看上下文 / 花费、压缩上下文等）。
- 📎：附加图片或文件；也可以直接粘贴图片。
- 输入框下面一行：当前模型、**权限模式**（点一下就能换）、这一轮的用时和输出量。

## 对话

- **回车发送**；粘贴多行文字没问题。
- **生成中还能接着发**：回车 = 排队，等这一轮跑完再发；⚡ = 插话，递进正在跑的这一轮、不打断。排队的消息停在对话末尾，可以「立即发送」。
- **停止键只管停止**：排队的消息会挂起，不会自动发出。
- `/` 唤起斜杠命令，`@` 引用文件路径（输入时会弹出补全）。
- **给 Claude 递东西**：回形针附加文件；在相册、文件管理器、浏览器里点「分享 → cccodroid」，文件直接成为附件（文字插进输入框）；＋ 面板里的「截屏给 Claude」截下当前屏幕（要 Shizuku），分屏时连另一半一起截，「5 秒后截屏」留出时间切到别的应用，截完自动回来。
- **思考过程**默认折叠，点开才显示。
- **步骤折叠**：两段回复之间的工具调用（连同中间的思考）收成一行，例如「3 个步骤 · Bash … · 完成」，点开看每一步的参数和结果。有待你确认、执行失败或带图片的组会自动展开。
- **回复里的路径能点**：绝对路径（或 `file.js:12`）点一下就在查看器里打开；目录打开文件浏览器。网页链接在应用内浏览器里打开。
- 每条回复下面：**复制**（正文的 Markdown 原文）、**转发**（系统分享面板）。你自己的消息可以**复制**、**重发**（放回输入框）。
- 往上翻时右下角出现 ↓ 圆钮，点一下回到最新；有新输出时钮上会亮一个点。
- **目标（`/goal`）**：打 `/goal 完成条件`，Claude 会一轮接一轮干到条件满足为止。输入框上方显示目标、检查了几次、已用多久；达成后显示用了几轮、多长时间、多少 token。「放弃」会停下当前这一轮并清掉目标。
- **后台任务**：Claude 在后台起的命令、子代理、工作流，会在输入框上方逐个列出来，每个都能单独「停止」。
- **任务清单**：Claude 干长活时会列清单（TaskCreate），输入框上方显示完成了几项、正在做哪一项；点一下展开整张清单，全部做完可以点 ✕ 收起。清单跟着会话走，下次打开还在。
- **子代理过程**：Claude 派出的子代理（Agent）做的每一步，收在那张 Agent 卡片下面的「子代理过程」里，点开能看到它跑了哪些命令、读了哪些文件、最后汇报了什么；跑着的时候卡片上会显示它正在做什么。以前的会话点开时才去读记录。
- **回退到这里**：你发的每条消息下面都有回退按钮。点了先算出这之后 Claude 改过哪些文件、增删多少行，再让你选「只撤销代码」或「撤销代码，并回到这里重新提问」。回到这里会另开一个会话、把这条消息放回输入框，原会话保留。只撤销编辑工具（Edit / Write）做的修改，用命令改的文件、装的包不会还原；升级到 v0.2.13 之前的消息没有留底，只能回退对话。
- **误删找回**：输入框里一段话被删空了（不是发出去的），输入框下面会出现「恢复刚才清掉的内容」，20 秒内点一下就回来；外接键盘在空输入框里按 ↑ 也行。

## 权限与安全

Claude 要改文件、跑命令、联网前，按**权限模式**决定要不要先问你：

| 模式 | 行为 |
|---|---|
| 逐项确认（默认） | 读文件不问；改文件、跑命令、联网前先问 |
| 自动接受编辑 | 改文件不问，跑命令还要问 |
| 只做计划 | 只读和出计划，等你批准再动手 |
| 自动判断 | 由 Claude 的分类器判断哪些要问（实验） |
| 全部放行 | 什么都不问 —— 只在你信任当前任务、出了事能承受时用 |

- **确认卡**出现在对应的工具卡下面，输入框上方还有一条常驻提示，翻走了也看得见。可以「允许」「始终允许」（只用 Claude 自己建议的规则）或「拒绝」（可附一句理由，也可以拒绝并停止）。
- **计划待批准**：选「批准，逐项确认执行」或「批准，自动接受编辑」，这一选会改变之后的权限模式；也可以「再改改」。
- 几个确认请求排着队时，提示条上会显示「第 1/3 个」。
- **切到后台不丢活**：一轮跑完、或 Claude 等你确认时会发通知（不弹横幅）。通知里只有「拒绝」和「打开查看」—— 放行必须回到应用看完整命令。

## 会话

侧栏 →「会话」：

- 点一条切换过去；可以**重命名**、**删除**（先进回收站，30 天内可恢复）。
- **选择**：逐条勾选或全选，打包**导出**成 zip（保存到任意位置或直接分享）。
- **导入**：在另一台设备上导入 zip，就能接着聊。
- **断开当前**：下一条消息开新会话，旧会话留在列表里。
- 应用被系统杀掉后重开，没跑完的那一轮会标「已中断」并给「继续」按钮；排队的消息也都还在。

## 文件、查看器、终端、浏览器

**文件浏览器**（📁）：浏览工作区和附加目录；点文件在查看器里打开，可下载 / 另存到任意位置。

**查看器 / 编辑器**：

- 文本、代码直接改、直接存。打开之后磁盘上的文件被改过（比如 Claude 改了），保存前会先问你，不会悄悄覆盖。
- Markdown 渲染显示，可切到编辑；图片适应屏幕，点一下看原始大小；PDF 翻到哪页画哪页（支持中日韩文字和带密码的文件）。
- HTML 文件直接显示成网页（同目录的 CSS、JS、图片都能加载），文件一改自动刷新；可切到源码，也能在浏览器里打开。网页在单独的环境里运行，碰不到应用和你的会话。
- Office 文档：Word（docx）直接显示文字、标题、表格和图片；Excel（xlsx / xls / ods）显示成表格，底部切换工作表，点格子看完整内容和公式。PPT、旧版 doc 以及「原版式」按钮会用 LibreOffice 在后台转成 PDF 再显示（第一次用时点一下安装，下载约 190 MB；转好的会缓存，再开秒出）。

**终端**（>_）：

- 真正的终端，跑的是 Claude 用的同一个 bash 和工具链；可开多个标签。
- 底下一排补上手机键盘没有的键：Esc、Tab、粘住的 Ctrl / Alt、方向键、Home / End、PgUp / PgDn、粘贴、字号。
- 「文本视图」可以长按选择、复制输出。关掉面板终端照样在跑，回来时回放输出。

**应用内浏览器**（🌐）：

- 看本机开发服务最方便：地址栏输 `127.0.0.1:端口`。
- 回复里的网页链接也在这里打开；↗ 交给系统浏览器。登录授权页总是交给系统浏览器。

## 大屏与分屏

按**窗口宽度**自动分档（不看横竖屏）：

- 窄（手机竖屏、窄分屏）：单栏，文件 / 终端 / 浏览器盖满屏幕。
- 宽（≥ 840）：对话 + 右侧工作区，文件、查看器、终端、浏览器开在右边；分隔条可拖，双击复原。
- 更宽（≥ 1000）：再把侧栏常驻在左边，☰ 或 ✕ 收起。
- 同时开了几个窗格时，工作区顶上有标签切换；返回手势先关最近打开的那个。

## 设置

- **语言**：9 种界面语言，或跟随系统。
- **外观**：浅色 / 深色 / 跟随系统；启动页、安装页、内置浏览器都跟着这里走。
- **接口**：选厂商、填 Key、测试连接；账户登录也在这里。
- **模型**、**思考强度**（`--effort`，越高想得越多）、**输出风格**、**自动压缩窗口**（逼近这个 token 数时自动摘要历史）。
- **空闲压缩**（默认开）：用 Claude 账户或 Anthropic API Key 时，上下文超过 20 万 token 的会话闲置约 54 分钟、1 小时提示缓存快过期时，先自动压缩一次，回来接着聊不用把整段历史按全价重算。
- **附加目录**（`--add-dir`）：让 Claude 能读写工作区之外的目录，例如 `/sdcard/某个目录`；它们也会成为文件浏览器的快捷入口。
- **端侧小模型**：装好 llama-cpp 组件后，可以在手机上离线跑小模型聊天（扩展页 llama-cpp 组件下能一键下载 Qwen2.5 0.5B / 1.5B / 3B）。手机算力有限，只内置聊天模式；想自己折腾，可以写 `~/.cccodroid/local-mode.json` 开自定义模式，卡片上有一句现成的话，复制给云端模型就能让它帮你配。
- **通知**：任务跑完、等你确认时是否通知。
- **Shizuku**、**更新**、**排障**见后面几节。

## 扩展

侧栏 →「扩展」：

- **可选组件**：体积大的工具用得上再装，例如无头 Chromium 浏览器、GitHub CLI、Blender、Godot、LibreOffice、llama.cpp、GPU 驱动等。装之前核对签名和逐文件清单，卸载干净；每个组件自带一个技能，装好 Claude 就会用。
- **插件**：搜索官方目录或添加别的插件市场，安装 / 启用 / 停用 / 卸载。
- **技能**：从 zip 安装，或从官方技能库装。
- **MCP 服务器**：添加 / 移除。

改动在**下一条消息**生效。全部经 Claude Code 自己的 `claude plugin` / `claude mcp` 命令完成；需要执行命令才能装的东西会先给你过目。

侧栏 →「能力」能看到当前可用的斜杠命令、工具、技能、子代理、MCP 服务器和插件。

**Termux 仓库的包：`pkg`**（终端里，Claude 也会用）：

- `pkg install rust` 这样装，`pkg search 关键词` 搜，`pkg uninstall` 卸（不再被需要的依赖一起卸）。包按 cccodroid 的路径改写后原样运行。
- 本机实测过的包直接装：rust / cargo、golang、zig、ruby、php、lua、python-numpy、neovim、vim、tmux、redis、postgresql 等，`pkg verified` 看全表。别的包要加 `--unverified`，装完自己试试能不能用。
- 工具包自带的包（clang、python、node…）不经 pkg 升级，随工具包更新。更新工具包后，之前用 pkg 装的包要 `pkg restore` 装回（会提示）。

## Shizuku 与系统权限（可选）

- 设置页「一键安装并激活」：从 Shizuku 官方下载（核对签名），经「无线调试」激活，不用电脑。配对码在屏幕顶部的通知里填。
- 激活后，终端和 Claude 都能用 `priv '<命令>'` 以 shell 身份执行 `pm` / `am` / `settings` / `logcat` / `screencap` 等。
- 重启手机后，cccodroid 会自己打开无线调试、重新激活（需连着 Wi‑Fi）。
- 有 Shizuku 时，保活更稳，应用更新也能在空闲时静默安装。
- 每条经 `priv` 执行的命令都会记下来（时间、谁发起的、命令、退出码），设置页 Shizuku 一栏点「特权命令记录」查看。只存在本机。

## 内存管家（可选，默认关）

跑编译、渲染、转码这类重活时，后台那些「杀了又活」的应用会跟你抢内存。内存管家可以先把它们停掉，并在重活跑完之前一直压着。要用 Shizuku，在设置页打开。

- **不会被停的**：你正在看的、分屏的、挂着前台通知的（代理、音乐）、桌面、输入法、无障碍服务、VPN、Shizuku、系统组件，以及上面这些依赖的组件。安卓停一个应用时，会把加载了它的应用一起带走，所以依赖的组件也要保护。
- **白名单**：想一直收消息的应用（比如聊天软件）加进去，每行一个包名。包名可以在系统的应用详情里看，或者先点「查看内存」。
- **立即清理**：停掉其余的后台应用。它们之后可能会被系统重新唤起。
- **终端里**：
  - `cc-mem status` 看内存账；
  - `cc-mem run -- 命令` 跑重活：开跑前清场，跑的时候谁复活就再停谁，结束后报告；
  - `cc-mem tame 包名` 长期限制某个应用的后台，`cc-mem untame` 恢复；
  - `make -j$(cc-mem jobs)`：按现在的可用内存给出安全的并行数（不用打开内存管家也能用）。
- 被停掉的应用，在你下次打开它之前可能收不到消息。这是开关默认关闭的原因。

## 更新与修复

- **自动更新**（默认开）：Claude Code 从官方渠道静默更新；cccodroid 本体下载后核对签名再提醒安装；开发工具包只在 Wi‑Fi 下预先下载、下次打开时替换，你用 pip / npm -g 装的东西会保留。
- 更新之间不会互相打断；替换前先按发布清单核对，核对不过就不动旧版；中途被打断，下次打开接着装完或退回旧版。
- **校验 / 修复**：逐个文件核对工具包哈希；修复会重装同一版本，你自己装的包照常保留。
- **本地文件…**：用已经下好的工具包文件来装（离线、或者网络太慢时）。装之前会核对它是不是已发布的版本，对不上会明确提醒、由你决定。
- **修复账本**：每次安装、校验、修复、启动恢复都记一笔，设置页可查。

## 排障

- **安全模式**：钩子、插件、MCP 或 CLAUDE.md 把东西弄坏了，就打开它 —— Claude Code 以 `--safe-mode` 启动，自定义项一概不加载；登录、Key、会话、模型照旧，关掉即恢复。
- **我卡住了 · 打包诊断**：把诊断信息、应用日志、网关日志和修复账本打成 zip 交给系统分享。打包前列出包里有什么；密钥、令牌、邮箱和你的消息内容会先抹掉，会话记录不在包里。
- **到 GitHub 反馈**：打开 GitHub 的新建 Issue 页面，机型、系统和各家 ROM 版本、自检结果、装了哪些组件都已经填好，你只写遇到了什么。不放日志和对话；需要 GitHub 账号。各品牌后台设置和芯片限制见网站的「已知问题」。
- **划不动了（冻结脱困）**：偶尔所有地方都划不动，按钮却照常能点。这是系统 WebView 自己的毛病，不是你的操作问题，我们还没法根治。App 会自动检测并在一秒左右恢复，正在进行的回复不受影响，没发出去的字会填回去；没自动恢复就点顶栏的 ❄。详情见《已知问题》第 2 条。
- **跑一次 doctor**：设置页最下面，调用 Claude Code 自带的自检。
- **常见情况**：
  - 回复一直「生成中」没动静：看状态栏和网络；必要时停止后重发，或打包诊断。
  - 打不开某个文件 / 目录：确认它在工作区或附加目录里。
  - 装组件失败：多半是网络或空间，修好后重试会续传。
- 还没查清的问题见项目文档《已知问题》。

## 进阶用法

**终端里直接用工具链**：

```
python3 -m venv .venv && . .venv/bin/activate && pip install requests
npm i -g typescript
pkg install rust && cargo new demo                # Termux 仓库的包
clang hello.c -o hello && ./hello
ffmpeg -i in.mp4 -c:v h264_mediacodec out.mp4   # 手机硬件编码
cccodroid-selftest                                # 逐项自检工具链
```

**让 Claude 记住你的习惯**：在项目目录放 `CLAUDE.md`（或全局的 `~/.claude/CLAUDE.md`），写上约定、常用命令、注意事项，每次对话都会读到。

**自己的斜杠命令和技能**：

- `~/.claude/commands/名字.md` → 就多了一个 `/名字` 命令，文件内容是给 Claude 的提示。
- `~/.claude/skills/名字/SKILL.md` → 一个技能：开头写清楚「什么时候用」，Claude 判断用得上就会读。

**开发网页 / 服务**：让 Claude 把服务起在 `127.0.0.1:端口`，用应用内浏览器打开；宽屏时边看网页边看对话。

**处理工作区外的文件**：设置 → 附加目录，加上 `/sdcard/Download` 之类的目录。

**USB 调试另一台手机**：OTG 线连上，终端里运行 `usb-adb`，之后照常 `adb devices / install / shell`。

**省上下文**：长会话用 `/compact` 压缩历史，或设「自动压缩窗口」；不相关的新任务开新会话。

**模型与花费**：`/model` 切换模型，`/effort` 调思考强度，`/cost`、`/usage` 看花费与额度（账户登录时设置页的账户卡片也显示 5 小时 / 每周额度）。

**调试界面本身**：网页调试默认关闭（开着时连上 adb 的电脑就能读界面内容）。要用 Chrome 的 `chrome://inspect` 调试，在终端里 `touch ~/.webdebug` 再重开应用；用完 `rm ~/.webdebug`。
